华为 FusionCompute 底层安装

配置要求 ​

CPU：16X

DIMM：16GiB

Disk：120GiB

系统镜像版本：FusionCompute VRM 8.0.0

系统安装 ​

挂载镜像后开机进入开始界面，选择 Install

进入配置界面

配置网络 ​

选择 Network-IPv4

选择 Manual address configuration，也就是静态IP地址

配置主机名 ​

配置密码 ​

安装系统 ​

后面全部OK就行了

系统配置 ​

在网页输入 https://172.16.2.1:8443进入网页管理

同意协议继续

默认账号：admin

默认密码：IaaS@PORTAL-CLOUD8!

修改密码

之后就直接进入主页

添加集群 ​

添加节点 ​

这里需要先安装节点主机

点击资源池

选择添加主机，同时配置IP地址信息

确认配置
